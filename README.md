# Student Result Management System (C)

📌 Project Description

The Student Result Management System is a console-based application developed using the C programming language.
This project is designed to manage and display the academic results of students efficiently.

The system stores details of 100 students including:

1. Roll Number
2. Student Name
3. Python Marks
4. JavaScript Marks
5. C Programming Marks
6. Total Marks
7. Percentage
8. Grade

The application automatically calculates the total marks, percentage, and grade of each student and provides different menu options to display and search student records.

🚀 Features:
Display all student records
Search student by roll number
Display Grade A students
Display Grade B students
Display Grade C students
Display Grade D students
Display Grade F students

Automatic calculation of:
Total Marks
Percentage
Grade
Predefined data for 100 students
Menu-driven console application
